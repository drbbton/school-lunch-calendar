Deephaven Lunch Calendar

Automatically updated Deephaven Elementary lunch calendar, built daily from the Minnetonka Nutrislice menu.

Or add this URL as a subscribed calendar:
https://drbbton.github.io/school-lunch-calendar/deephaven-lunch.ics

iPhone / iPad

Tap the Subscribe button above, then tap Subscribe. Or open Settings › Apps › Calendar › Calendar Accounts › Add Account › Other › Add Subscribed Calendar, and paste the URL.

Mac

In Calendar choose File › New Calendar Subscription, paste the URL, and set Location to iCloud so it syncs to your other devices.

Subscribe rather than download: a downloaded .ics is a one-time copy and will not update. Menus appear once Minnetonka publishes them on Nutrislice.
